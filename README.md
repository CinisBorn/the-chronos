# Description

Chronos displays time-related information in the console, including, but not limited to:

- General information (date and time);
- Number of weeks in the current year;
- Number of days in the current year;
- Remaining time;
- Available time, calculated based on when the user wakes up.

The idea is to quantify time. Humans can sometimes lose their sense of how much time is passing, but when time is quantified and made visible, it can increase awareness of how we spend it.
